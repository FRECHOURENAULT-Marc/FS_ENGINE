# FE-Engine
A 3D game engine developed with DX12 in C++ during 4 weeks.

## Setup
- Run bin/make.bat
- Open ide/FSEngine.sln
- Choose "Demo" project as starting project
- We suggest you to run it in Debug mode

### Additionnal notes
The demo game is not polished and not finished (engine too).  
The demo game contains bugs and crashs in some specific conditions (not a problem in general).  
Can run without graphics card.  
Feel free to try the engine yourself.
